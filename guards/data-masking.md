# 数据脱敏规则

查询结果展示给用户时，以下字段做脱敏处理。**不修改原始数据，只在展示时处理。**

## 脱敏规则

### 必须脱敏（PII 字段）

| 字段类型 | 识别方式 | 脱敏方式 | 示例 |
|---------|---------|---------|------|
| 手机号 | 11位数字，1开头 | 保留前3后4 | 138****5678 |
| 身份证号 | 18位数字+X | 保留前6后4 | 320106****1234 |
| 银行卡号 | 16-19位数字 | 保留前4后4 | 6222****7890 |
| 邮箱地址 | 含 @ 的字符串，字段名含 email/mail | @前保留首2位 + **** | do****@gmail.com |
| 车牌号 | 省份简称+字母+5位字符 | 保留首2位 + **** | 苏A****5 |
| 地址 | 字段名含 address/addr | 保留省市 + **** | 江苏省南京市**** |
| 姓名 | 字段名含 name/nick_name/real_name（且值为2-4个中文字符） | 保留姓 + * | 张* / 王** |

### 完全隐藏（敏感凭证）

| 字段类型 | 识别方式 | 脱敏方式 | 示例 |
|---------|---------|---------|------|
| 密码/密钥字段 | 字段名含 password/secret/key/token/credential | 完全隐藏 | ****** |
| 支付宝/微信账号 | 字段名含 alipay/wxpay/open_id/unionid | 保留前4 + **** | 2088**** |
| Cookie/Session | 字段名含 cookie/session/jwt | 完全隐藏 | ****** |

## 字段名匹配规则

脱敏的字段名匹配为**大小写不敏感、下划线不敏感**：
- `user_phone` / `userPhone` / `USER_PHONE` 都匹配「手机号」
- `id_card` / `idCard` / `identity_no` 都匹配「身份证号」
- 值的格式也参与判断（如 11 位数字 1 开头 → 手机号，即使字段名不含 phone）

## 触发时机

- 所有展示给用户的查询结果，逐行逐字段检查
- 用户明确要求「显示完整手机号」时，可一次性展示，但记录到审计日志
- 临时文件中的数据**不脱敏**（原始数据），仅在展示给用户时脱敏

## 不脱敏的字段

- 订单号、record_id、trade_seq（业务标识，非 PII）
- 时间戳、金额、状态码
- 内部 ID（user_id、org_id、station_id 等，纯数字 ID 不含个人信息）
- 充电桩编码、电站 ID
- 错误码、异常类名
